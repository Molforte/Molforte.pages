你好，我是 **Molforte**——白天写代码，偶尔晚上也写，习惯把踩过的坑和想明白的事记下来。

这个博客是那些记录的集合：

- 技术实践与工具折腾；
- 读书与生活里冒出来的随笔；
- 一些只有自己看得懂的草稿。

它没有任何顶栏，也不打算有。功能都贴在它们该在的地方：文末是上一篇与下一篇，导航收在侧栏，其余交给留白。

### 关于本站

- 文章是纯 Markdown，放在仓库的 `content/` 里；
- 用 React 构建，部署在 GitHub Pages，没有用任何博客框架；
- 源码在 [GitHub](https://github.com/Molforte/Molforte.pages)，欢迎去看或提意见。

想说的话，欢迎通过 GitHub 联系我。看到这里的人，谢谢你读完了。
